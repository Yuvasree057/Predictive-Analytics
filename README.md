# Predictive Analytics Dashboard

Developed by **Yuva Sree**

## About the Project

This is a Streamlit-based Predictive Analytics Dashboard that uses historical data to forecast future trends using Machine Learning.

Users can upload a CSV file, select a date column and target variable, choose a predictive model, and generate forecasts through an interactive dashboard.

## Features

- Upload historical data (CSV)
- Dataset preview
- Data preprocessing
- Automatic date feature extraction
- Historical trend visualization
- Machine Learning prediction
- Future forecasting
- Interactive dashboard

## Technologies Used

- Python
- Streamlit
- Pandas
- NumPy
- Scikit-learn
- Plotly

## How to Run

1. Clone the repository

```bash
git clone https://github.com/Yuvasree557/predictive-analytics-dashboard.git
```

2. Install dependencies

```bash
pip install -r requirements.txt
```

3. Run the application

```bash
streamlit run app.py
```

## Dataset

The application accepts CSV files containing:

- Date column
- Target variable (e.g., Sales, Revenue, Demand)

## Machine Learning Model

- Linear Regression
